### 1. `app/cad/dwg.py` — ODA 失败不再静默吞错（原建议 🟡）
**问题**：`subprocess.run(...)` 的返回值 `proc` 被丢弃，仅以"输出 DXF 文件是否存在"判断成败。ODA 转换失败时无精确报错，调用链 `reader.py` 只能笼统提示"DWG 解析失败"。

**修复**：
```python
proc = subprocess.run([exe, ...], capture_output=True, text=True, timeout=120)
target = out / (dwg.stem + ".dxf")
if not target.exists():
    raise RuntimeError(
        f"ODA 转换失败（退出码 {proc.returncode}），未生成 DXF: {target}\n"
        f"命令: {exe} {dwg.parent} {out} {version} DXF 0 1\n"
        f"stdout: {proc.stdout.strip()}\nstderr: {proc.stderr.strip()}"
    )
if proc.returncode != 0:
    logging.warning(f"ODA 转换退出码 {proc.returncode} 但已生成 DXF，忽略: {target}")
return str(target)
```
- `proc` 不再未使用（消除 pyflakes 告警）。
- ODA 未安装时仍走 `if not exe: return None` 早期返回，行为不变。
