## 核心工作流程

### 1. 项目初始化流程
```
新建项目 → 创建数据库 → 初始化配置 → 准备就绪
```

### 2. 图纸导入流程
```
选择DWG/DXF → 三阶段并行处理：
  ├─ 阶段1: DWG批量转换 (ezdwg/ODA)
  ├─ 阶段2: 进程池并行解析 (parse_dxf)
  └─ 阶段3: 主进程流式入库 (add_sheet + replace_entities)
```

### 3. BOQ导入流程
```
选择Excel → 探测表头 → 解析条目 → 过滤合同声明 → 入库
```

### 4. 图例标定流程（块语义理解）
```
识别所有块 → 分层处理：
  ├─ 第1层: 规则预筛 (is_building_by_rule)
  │   └─ 门窗墙柱洁具等建筑块 → 直接标记"建筑"
  ├─ 第2层: LLM快筛 (llm_filter_devices)
  │   └─ 设备/线缆/建筑/其他 分类
  └─ 第3层: LLM完整标定 (llm_suggest_legend)
      └─ 设备类型/规格/单位/计量规则
→ 人工确认 → 存储标定信息
```

### 5. 绑定工作台流程（BOQ绑定）
```
提取工程对象 → 分层候选生成：
  ├─ 第1层: 历史确认复用 (最高优先级)
  │   └─ 同块/同图层的历史ACCEPTED候选
  ├─ 第2层: 规则匹配 (确定性，0成本)
  │   ├─ 关键词匹配 (block_name/layer_name/system/spec)
  │   └─ 学科冲突检测
  ├─ 第3层: 语义召回 (Embedding相似度)
  │   └─ EO文本 ↔ BOQ文本 余弦相似度
  └─ 第4层: LLM重排序 (大模型分析)
      └─ 在候选子集内选择/排序
→ 人工审核队列 → 确认/拒绝 → 建立正式映射
```

### 6. AI算量流程（单图/文件夹）
```
解析图纸 → 聚合数据 → 分层分类：
  ├─ 第1层: 规则分类 (秒级，0成本)
  │   ├─ 图层名匹配 → 设备/线缆/面积
  │   ├─ 块引用计数 → 图例标定优先
  │   └─ 几何长度/面积计算
  ├─ 第2层: LLM分类 (大模型分析)
  │   └─ 汇总数据 → BOQ条目
  └─ 第3层: 冲突检测 + 质量门槛
      └─ 自动fallback修正
→ 导出BOQ草稿
```

### 7. 手动算量流程
```
选择BOQ条目 → 在图纸上选择实体：
  ├─ 双击单个实体
  ├─ Shift+框选多个实体
  ├─ 右键图层树批量关联
  └─ 右键块树批量关联
→ 建立映射 → 计算数量 → 实时更新
```

### 8. 导出报告流程
```
计算所有条目数量 → 生成Excel报告 → 颜色标注差异
```

## 数据库表结构

### 核心表
```
project          - 项目信息
sheet            - 图纸信息（含blocks_json缓存）
entity           - CAD实体（几何+属性）
boq_item         - BOQ清单条目
mapping          - 实体→BOQ映射（三种模式）
```

### 智能表
```
block_legend     - 块图例标定（块名→设备语义）
engineering_object - 工程对象（从实体提取）
binding_candidate - 绑定候选（待审核）
symbol_library   - 知识库（人工标定）
llm_run          - LLM调用审计
project_config   - 项目配置（图层/设备规则）
llm_settings     - LLM全局配置（5种后端）
```

## 关键设计原则

### 1. 分层覆盖原则
```
规则层（0成本）→ 语义层（低成本）→ LLM层（高成本）
确保：覆盖率100%，成本最小化
```

### 2. 人工确认优先原则
```
人工已确认的标定 → 不被LLM覆盖
历史确认的绑定 → 优先复用
```

### 3. 渐进式智能原则
```
规则引擎（确定性）→ 语义匹配（概率性）→ LLM分析（智能性）
每一层都为下一层提供候选子集
```

### 4. 审计追溯原则
```
所有LLM调用 → 记录到llm_run表
所有候选状态 → PENDING/ACCEPTED/REJECTED/SUPERSEDED
所有映射关系 → 可追溯到实体/图层/块
```

## 性能优化策略

### 1. 缓存策略
- 解析缓存：避免重复解析DWG/DXF
- 嵌入缓存：避免重复计算向量
- 图例缓存：块标定结果跨图纸复用

### 2. 并行处理
- 图纸导入：三阶段并行流水线
- AI算量：文件夹批量处理
- 规则匹配：批量关键词匹配

### 3. 增量更新
- 工程对象提取：幂等重建（先清旧）
- 绑定候选：作废旧PENDING（保持最新）
- 图例标定：增量更新（不覆盖人工确认）

## 扩展性设计

### 1. LLM后端可插拔
- 支持5种后端：Ollama/DashScope/OpenAI/DeepSeek/Custom
- 自动fallback机制
- 质量门槛控制

### 2. 规则引擎可配置
- 项目级图层筛选规则
- 设备筛选规则
- 建筑背景识别规则

### 3. 知识库可积累
- 人工标定的符号库
- 历史确认的绑定
- 行业标准规范
